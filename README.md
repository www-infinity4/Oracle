# Oracle — one Phi interface

This is the **canonical presentation system** for QuantaPhi, Infinity Phi-style cards, Omni Phi, Builder Reserve, Bitcoin Crusher, and Oracle Octaves. Do not create another arbitrary card/button template.

## Card compatibility contract

- Match **the same visual geometry**: 24px card corners, balanced internal spacing, consistent readable titles, electric controlled edges, uniform button arrangement, and 44px minimum touch targets.
- **Preserve card type/color**: purple research and assimilation, red reader, yellow media/data, blue source or technical, and the original product-specific machinery. Color and imagery can differ; spacing, button heights, type size, and action placement must not.
- **One button grammar**: 999px rounded pills, 44px minimum height, 12–13px readable weight, centered multiline labels without overlap, white secondary pills, violet primary pills. Buttons stay functional and accessible.
- **Prefer existing Infinity Phi control geometry** over older disconnected CSS templates. New builders should adopt `oracle-interface.css` and DesiPhi's `oracle` theme. Do not overwrite functioning players, piano keys, wallet events, original slot animations or original research content for styling.
- **No phony connections**: only claim successful wallet rewards after signed-in cloud acknowledgment; actual radio only after audio playback starts; local demos are never production ledgers.
- **Mobile first**: at 390px or less, keep actions tappable, labels wrapped cleanly and no horizontal overflow. Obey reduced-motion settings.

Canonical CSS: `/oracle-interface.css` on `quantaphi.org`. Source is `www-infinity4/Oracle/oracle-interface.css`.
